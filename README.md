# Kriti: מאמן פרזנטציות למעצבים

כלי AI להכנה לפרזנטציה: מעלים מצגת, הכלי לומד אותה, מתאמנים מול מצלמה ומיקרופון ומקבלים משוב על התוכן, שפת הגוף והקול. אחר כך אפשר לנהל שיחה על המשוב ולנסות שוב. הכלי לומד מהדירוגים שנותנים להערות שלו.

## מה יש בפנים

**הכנה**
- העלאת מצגת כ-PDF (או תמונות של שקופיות). לצד כל שקופית יש תיבת הערות, שמשמשת להסביר שקופיות בלי טקסט.
- בחירת דגשים: קשר עין, ידיים, יציבה, תנועה, הבעות פנים, קצב, טון, עוצמה, רהיטות, דיקציה, מילות מילוי, ביטחון, התלהבות, זמנים וכיסוי תוכן. יש גם שדה חופשי.
- הגדרת זמן מתוכנן ושפת ההצגה (עברית או אנגלית).

**ניתוח המצגת**
Claude עובר על כל שקופית וכותב:
- סיפור במשפט אחד
- נקודות מפתח ו"אסור לפספס" לכל שקופית
- בדיקת מבנה של פרזנטציית עיצוב
- שאלות צפויות מהמנחים

**חזרה**
- ההקלטה נעשית רק מתוך האפליקציה, ואין העלאה מהגלריה. בווידאו רואים את המציג ולצידו את השקופית הנוכחית.
- אפשר להקליט את כל המצגת או שקופית אחת. מעבר בין שקופיות נעשה בחיצים, ברווח או בקליקר.
- טיימר לכל הקלטה. כשהזמן עובר מופיעה התראה קטנה, וההקלטה ממשיכה עד שעוצרים אותה.
- ניתוח בזמן אמת במחשב של המשתמש:
  - **פנים** (MediaPipe): קשר עין, מבט למטה, חיוך, הבעתיות, מצמוצים
  - **ידיים**: תנועות, ידיים קפואות, נגיעות בפנים
  - **גוף**: תזוזה, ידיים שלובות, יציבה
  - **קול**: עוצמה, גיוון בטון, הפסקות
  - **דיבור** (תמלול בדפדפן): מילים לדקה, מילות מילוי, והשוואת מה שנאמר מול נקודות המפתח

**משוב**
- ציון כללי, נקודות חוזק, משוב לפי נושא (הדגשים שנבחרו מופיעים ראשונים), כיסוי תוכן לפי שקופית (מה נאמר ומה פוספס), זמנים ותוכנית פעולה.
- 👍 / 👎 על כל הערה. ב-👎 נפתחת שאלה "מה לא היה מדויק?". הדירוגים נשמרים ומשפיעים על המשוב הבא.
- צ'אט על המשוב, בכתב או בהודעה קולית 🎙.
- כשמסיימים את השיחה: דירוג כללי, ואז הצעה לניסיון נוסף עם מטרות מהמשוב (כל המצגת או שקופית ספציפית) או לסשן חדש.
- בניסיון חוזר הכלי בודק אם המטרות השתפרו ומשווה לניסיון הקודם.
- ממשק בעברית ובאנגלית, עם החלפה בכפתור למעלה.

## פריסה ל-Render (כמו Jan-Ken)

1. **מפתח API:** נכנסים ל-https://console.anthropic.com, יוצרים API key ומוסיפים קרדיט. כל ניתוח עולה סנטים בודדים, וניתוח מצגת ארוכה עולה קצת יותר.
2. **GitHub:** יוצרים ריפו חדש (למשל `kriti`) ומעלים אליו את כל התיקייה, כולל `server.js`, `package.json`, `render.yaml` ו-`public/`.
3. **Render:** הולכים ל-New → Web Service ובוחרים את הריפו. ההגדרות:
   - Runtime: **Node**
   - Build Command: `echo no build needed`
   - Start Command: `node server.js`
   - Environment → Add variable: `ANTHROPIC_API_KEY` = המפתח שיצרת
   - לא חובה: `CLAUDE_MODEL`, כדי להחליף מודל. ברירת המחדל היא `claude-sonnet-5-5`.
4. מחכים לסיום הפריסה, פותחים את הקישור **ב-Chrome** ומאשרים מצלמה ומיקרופון.

> המפתח נשמר רק בשרת ולא מגיע לדפדפן. אין צורך ב-`npm install`, כי לשרת אין תלויות.

## הרצה מקומית

```bash
ANTHROPIC_API_KEY=sk-ant-... node server.js
# ואז לפתוח http://localhost:3000
```

## הערות חשובות

- **דפדפן:** כדאי להשתמש ב-Chrome או Edge. תמלול הדיבור משתמש ב-Web Speech API, שלא נתמך ב-Firefox. בלי תמלול, המשוב על הגוף והקול עובד, אבל בדיקת כיסוי התוכן לא.
- **פרטיות:** הווידאו לא עולה לשום מקום. Claude מקבל רק את המספרים המסוכמים, את התמלול, עד 6 תמונות קטנות מהחזרה ואת שקופיות המצגת.
- **שמירה:** סשנים, הערות, משוב ודירוגים נשמרים בדפדפן (IndexedDB ו-localStorage). הסרטונים עצמם נשמרים רק כל עוד העמוד פתוח, ולכן יש כפתור "הורדת הסרטון".
- **מילות מילוי:** התמלול של Chrome מפיל חלק מה"אממ" וה"אהה", ולכן הספירה היא הערכה מינימלית. ה-AI יודע זאת ולוקח את זה בחשבון.
- **המדדים הם הערכה:** "קשר עין" פירושו מבט למצלמה. כדי לקבל את המשוב הכי מדויק, כדאי להציב את המצלמה בגובה העיניים ולעמוד כך שרואים פלג גוף עליון וידיים.
